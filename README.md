# Tree Escape Living — Bespoke Furniture Boutique & Atelier

> **"Not a furniture shop. An atelier for custom living."**

A digital storefront for **Tree Escape Living**, a bespoke furniture boutique and craft carpentry atelier based in **Yamare Village, Sarjapur Road / Dommasandra, Bengaluru, Karnataka**.

---

## 🌲 Key Features

- **Bespoke Commission Archive**: Showcases past custom living suites, dining tables, cane beds, and executive desks with real wood provenance.
- **Interactive Ballpark Price & Lead Time Estimator**: Live calculator allowing clients to configure furniture type, dimensions, and hardwood species (Burma Teak, Indian Sheesham, American White Oak) with 1-click WhatsApp inquiry.
- **5-Step Atelier Journey**: Clear walkthrough of the collaborative custom process from in-home laser measurement to 3D CAD modeling and white-glove installation.
- **Project Moodboard Drawer**: Clients save pieces and send their curated moodboard directly to the workshop on WhatsApp.
- **Trade & Architect Collaboration Portal**: Tailored for Bengaluru interior designers and architects with 3D CAD file access and trade terms.
- **Yamare Studio & In-Home Measurement Scheduler**: Dual-tab booking for private studio visits and in-home laser measurement consultations.

---

## 🛠️ Built With

- Pure Semantic HTML5
- Responsive Modern CSS (CSS Grid, Flexbox, CSS Variables, Clamp Typography)
- Vanilla JavaScript (Local storage persistence, live cost calculator math, interactive modals)
- Zero external build dependencies — runs directly in any browser and on **GitHub Pages**.
